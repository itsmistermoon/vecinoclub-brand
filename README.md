# VecinoClub · identidad de marca

Fuente de verdad de la identidad visual de VecinoClub, independiente de la plataforma de fidelización y de la landing.

- `tokens/vecinoclub.css`: paleta cálida aprobada para temas claro y oscuro. El naranja `#fb772a` es el mismo en ambos temas.
- `assets/identity/`: logotipos y variantes monocromáticas aprobadas.
- `assets/app-icons/`: iconos de aplicación.
- `fonts/`: Rubik y Barlow Condensed, con sus licencias OFL.
- `DESIGN.md`: reglas de uso y límites de la marca.

Los consumidores copian una revisión fijada de este repositorio a sus builds. Las copias no se editan a mano. La plataforma conserva sus tokens neutros de interfaz, componentes y personalización limitada por comercio. Los colores cálidos se aplican solo a superficies explícitamente identificadas como VecinoClub.
